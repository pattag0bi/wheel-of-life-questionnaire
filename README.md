# Wheel of Life questionnaire

An interactive, one-question-at-a-time version of the Wheel of Life self-assessment: 8 areas, 81 aspects, gradient themes that change per area, and a downloadable PNG of your wheel.

- Open `index.html` in a browser. No build step.
- Answers autosave in your browser (localStorage) and never leave your device.
- Scoring (simple/weighted average, gut-vs-aspects gap flag) follows the original spreadsheet.
- Add `?test` to the URL to run the built-in scoring self-tests in the console.
